About me

I've always liked figuring out how stuff actually works. Not just reading about it, but taking it apart, measuring it, and seeing what actually makes it better instead of just guessing.

Honestly my interest in engineering isn't tied to one specific thing. I just find tradeoffs interesting, like weight vs. strength, or efficiency vs. output, or cost vs. performance. They're not really abstract to me, I'm dealing with them pretty much every time I build something.

Essentially every project I do goes the same way: set a baseline, change one thing, measure what happened, and repeat. I think that's pretty much what engineers do for a living, I'm just doing it with an RC car and a spreadsheet for now.

I want to study mechanical engineering and eventually design and build high-performance mechanical systems. After that I'd like to work as an engineer and eventually get a master's degree. Everything I'm doing right now, the classes, this project, all the data, is kind of pointing toward that.

Systems thinking

I want to actually understand how parts work together, not just what each one does on its own, but why the whole thing acts the way it does once real-world stuff gets involved.

Data over instinct

Every change I make gets measured somehow. I don't really trust my gut on this stuff when I can just go get the actual number.

Purposeful iteration

V3 has to actually be better than V2 for a reason I can point to. If I can't explain why it's better, I'm not really engineering, I'm just guessing.

RC Dynamometer Project

Started as just a speed sensor, turned into an actual testing rig.

Where it started: I saw a video of a Ferrari on a dyno and wanted to build one for my RC car. The listing for the car says it tops out at 18 mph, and I wanted to check that for myself.

What I built: A low-cost RC dynamometer that uses a magnet, a Hall sensor, and an Arduino to turn pulses into RPM and speed. The car is the test subject, but the dyno is really the project. It got me into mechanical design, wiring up sensors, and the physics behind RPM and speed. V1 was me learning the sensor and sketching ideas, V2 got it working, and V3 made the results much more consistent.

Results at a glance: Run-to-run variation in average speed dropped from about 20% in V2 to about 5% in V3. The roller's top speed was 18.62 mph at 6,360 RPM, in line with the 18 mph listed for the car.

Jump to V1, V2, or V3.

V1: Learning and planning

V1 was the planning stage. There was no stand, no mount, and nothing measuring anything yet. I wired the Hall sensor up on a breadboard to see how it worked, and I found out that only one side of a magnet triggers it. I also sketched a few ideas for a stand and clip. The clip I designed ended up too tight to work, and a circular mounting point I tried on top wasn't strong enough and slid around too much.

V2: Desk-clip stand

What I built

  • Desk-clip stand: Just a stand that clips into my desk so the rig stays put while the car's running. It's not perfect since the desk itself flexes a little, but it's good enough to get a real reading.
  • Hall sensor and magnet: Magnet taped to the wheel, Hall sensor propped nearby to pick it up every time it goes around. That's the whole electrical side, and it's basically what makes any of this possible.
  • How it measures: The car's motor spins the wheel, I'm not spinning it by hand. What I am doing by hand is holding the chassis down, because it vibrates a lot at full throttle. Pulses turn into RPM and top speed. Nothing fancy, but it works, and it's what V3 ends up building on.

How it works

  1. The motor drives the wheel while I hold the chassis steady.
  2. The magnet on the wheel sweeps past the sensor once per rotation.
  3. The Hall sensor fires a pulse every time the magnet passes.
  4. The Arduino counts pulses over a set window.
  5. The pulse count turns into RPM and wheel speed.

Results

Average RPM and average speed are each from 5 separate 30-second trials. This data isn't perfectly clean. It takes the wheel a second to get up to speed, so the early readings drag the average down, and there's some wobble from the wheel itself and a little give in the desk. Average speed varied by about 3 mph from the lowest trial to the highest (roughly 20%). It's not perfect, but it's a real starting point.

What I learned

  • Vibration control first. A rig that shakes gives you unreliable readings before you've even measured anything. Fixing the mounting problem first ended up mattering way more than the sensor itself.
  • A clean signal beats a complex one. One magnet, one Hall sensor, about as simple as it gets. But it gives a clean pulse every rotation, which is really all I needed to calculate RPM.
  • Prove the concept before adding complexity. Could've jumped straight to rollers and logging and graphs. Building the simplest possible version first confirmed the core idea works.

V3: Roller system (current build)

What I built

  • Custom-built roller: Built this roller myself, it just happens to look like a paint roller. Runs on ball bearings, mounted with hot glue. Went through three different stand designs before one actually held still under load.
  • Tiny magnet, zero vibration: Any magnet bigger than the smallest one I owned made the whole rig vibrate badly at speed. Dropping down to the tiny one fixed it.
  • Hands-free floating mount: Press-fit 3D-printed bracket holds the sensor board. Strong magnet on the bracket, another one under the desk, so it just snaps into place. No holding anything anymore, just pull the trigger.
  • Staples as conductors: The roller's mounted at 90 degrees, so the breadboard connections needed more reach to clear it. Plugged some spare staples straight into the breadboard as conductive material to extend things upward. Tape's only there to hold the tiny magnet on.

How it works

  1. I pull the trigger and the wheel drives the roller directly, completely hands-free.
  2. The custom roller spins on ball bearings.
  3. The tiny magnet on the roller sweeps past the floating sensor mount once per rotation.
  4. The Hall sensor fires a pulse every time the magnet passes.
  5. The code counts pulses, throws out the first 5 seconds of startup, and turns the rest into RPM and MPH over a 30-second run.

Results

Average RPM and average speed are each from 5 separate 30-second trials. Much tighter than V2. The roller and the floating sensor mount got rid of most of the noise, and average speed varied by only about 0.9 mph across the five runs (roughly 5%). The top roller speed was 18.62 mph at 6,360 RPM, which lines up with the 18 mph listed for the car. Run 5 dips a little, which fits with the battery sagging by the end. Results depend a lot on battery voltage, so I need to keep track of that going forward.

What I learned

  • Smaller magnet, zero vibration. I figured a bigger magnet meant a stronger signal. It actually threw the roller off balance at speed, and the smallest magnet I owned ended up being the fix.
  • Let the sensor float. Holding the sensor board by hand was causing its own vibration. Mounting it on a magnetic press-fit bracket got my hands out of it completely, the rig basically runs itself now.
  • Staples as conductive extensions. Didn't have the right length wire on hand, so I plugged spare staples right into the breadboard as conductive material to extend things up and clear of the roller. It's a cheap fix, but it works well.

V1: just testing the sensor (dyno_v1.ino)

This isn't even a real dyno sketch, it's literally just checking if the Hall sensor works. I'd pass a magnet over it and watch the Serial output flip between ON and OFF. This is also how I learned that only one side of the magnet actually triggers the sensor. Flip it around and it does nothing.

const int hallPin = 2;

void setup() {
  pinMode(hallPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(hallPin) == LOW) {
    Serial.println("ON");
  } else {
    Serial.println("OFF");
  }

  delay(100);
}
V2: Hall sensor RPM and speed reader (dyno_v2.ino)

Reads pulses off the Hall sensor, turns them into RPM and MPH, and tracks a full run on its own. An LED lights up while it's running and switches over once the wheel's been still for 2 seconds, so I get max/average stats per run without touching a laptop.

const int hallPin = 2;

const int runningLed = 8;
const int finishedLed = 13;

volatile long pulseCount = 0;

unsigned long lastCalcTime = 0;
unsigned long lastPulseTime = 0;
unsigned long sessionStart = 0;

const int interval = 500;
const int timeout = 2000;

const float wheelDiameterInches = 2.67717;

bool sessionActive = false;

long rpmSum = 0;
int rpmSamples = 0;

int maxRPM = 0;
float maxMPH = 0;

void setup() {
  pinMode(hallPin, INPUT);

  pinMode(runningLed, OUTPUT);
  pinMode(finishedLed, OUTPUT);

  digitalWrite(runningLed, LOW);
  digitalWrite(finishedLed, HIGH);

  Serial.begin(9600);
  Serial.println("RC RPM System Ready");

  attachInterrupt(digitalPinToInterrupt(hallPin), countPulse, FALLING);
}

void loop() {
  unsigned long now = millis();

  if (now - lastCalcTime >= interval) {
    lastCalcTime = now;

    long pulses = pulseCount;
    pulseCount = 0;

    int rpm = pulses * 120;

    if (rpm > 0) {

      lastPulseTime = now;

      if (!sessionActive) {
        sessionActive = true;

        digitalWrite(runningLed, HIGH);
        digitalWrite(finishedLed, LOW);

        sessionStart = now;

        rpmSum = 0;
        rpmSamples = 0;
        maxRPM = 0;
        maxMPH = 0;

        Serial.println("=== RUN STARTED ===");
      }

      rpmSum += rpm;
      rpmSamples++;

      if (rpm > maxRPM) {
        maxRPM = rpm;
      }

      float circumference = wheelDiameterInches * 3.14159;
      float mph = rpm * circumference * 60.0 / 63360.0;

      if (mph > maxMPH) {
        maxMPH = mph;
      }

      Serial.print("RPM: ");
      Serial.print(rpm);
      Serial.print(" | MPH: ");
      Serial.println(mph, 2);
    }
  }

  if (sessionActive && (now - lastPulseTime > timeout)) {

    sessionActive = false;

    digitalWrite(runningLed, LOW);
    digitalWrite(finishedLed, HIGH);

    float avgRPM = (rpmSamples > 0) ? (float)rpmSum / rpmSamples : 0;

    float circumference = wheelDiameterInches * 3.14159;
    float avgMPH = avgRPM * circumference * 60.0 / 63360.0;

    float runTime = (now - sessionStart) / 1000.0;

    Serial.println();
    Serial.println("===== RUN COMPLETE =====");

    Serial.print("Run Time (s): ");
    Serial.println(runTime, 2);

    Serial.print("Average RPM: ");
    Serial.println(avgRPM, 1);

    Serial.print("Max RPM: ");
    Serial.println(maxRPM);

    Serial.print("Average MPH: ");
    Serial.println(avgMPH, 2);

    Serial.print("Max MPH: ");
    Serial.println(maxMPH, 2);

    Serial.println("========================");
    Serial.println();
  }
}

void countPulse() {
  pulseCount++;
}
V3: roller dyno with auto run detection (dyno_v3.ino)

Rewrote this for the roller rig. A run starts on its own the second it picks up a Hall signal, throws out the first 5 seconds (that's just spin-up), and reports average/max RPM and MPH once the roller's been still for 2 seconds or 30 seconds have passed, whichever comes first.

const int hallPin = 2;

const int runningLed = 8;
const int finishedLed = 13;

const unsigned long TEST_DURATION = 30000;
const unsigned long STARTUP_EXCLUSION = 5000;

const unsigned long RPM_INTERVAL = 500;

const int ZERO_INTERVAL_LIMIT = 4;

const float rollerDiameterMM = 25.0;
const int magnetsPerRevolution = 1;

volatile long pulseCount = 0;

unsigned long lastCalcTime = 0;
unsigned long runStartTime = 0;

bool runActive = false;

int zeroIntervals = 0;

long rpmSum = 0;
int rpmSamples = 0;

int maxRPM = 0;
float maxMPH = 0;

void setup() {

  pinMode(hallPin, INPUT);

  pinMode(runningLed, OUTPUT);
  pinMode(finishedLed, OUTPUT);

  digitalWrite(runningLed, LOW);
  digitalWrite(finishedLed, HIGH);

  Serial.begin(9600);

  Serial.println();
  Serial.println("================================");
  Serial.println("      RC ROLLER DYNO V2");
  Serial.println("================================");
  Serial.println("Ready.");
  Serial.println("Waiting for first Hall signal...");
  Serial.println();

  attachInterrupt(
    digitalPinToInterrupt(hallPin),
    countPulse,
    FALLING
  );
}

void loop() {

  unsigned long now = millis();

  if (now - lastCalcTime >= RPM_INTERVAL) {

    lastCalcTime = now;

    noInterrupts();

    long pulses = pulseCount;
    pulseCount = 0;

    interrupts();

    if (!runActive) {

      if (pulses > 0) {

        runActive = true;

        runStartTime = now;

        zeroIntervals = 0;

        rpmSum = 0;
        rpmSamples = 0;

        maxRPM = 0;
        maxMPH = 0;

        digitalWrite(runningLed, HIGH);
        digitalWrite(finishedLed, LOW);

        Serial.println();
        Serial.println("================================");
        Serial.println("         RUN STARTED");
        Serial.println("================================");
        Serial.println("30 second timer started!");
        Serial.println();
      }

      return;
    }

    unsigned long elapsed = now - runStartTime;

    int rpm = 0;

    if (pulses > 0) {

      rpm = (pulses * 60000L) /
            RPM_INTERVAL /
            magnetsPerRevolution;

      zeroIntervals = 0;

    } else {

      rpm = 0;

      zeroIntervals++;

    }

    float circumferenceMM =
      rollerDiameterMM * 3.14159;

    float mph =
      rpm * circumferenceMM * 60.0 /
      1609344.0;

    Serial.print("Time: ");
    Serial.print(elapsed / 1000.0, 1);

    Serial.print("s | RPM: ");
    Serial.print(rpm);

    Serial.print(" | MPH: ");
    Serial.print(mph, 2);

    if (elapsed < STARTUP_EXCLUSION) {
      Serial.println(" | STARTUP");
    } else {
      Serial.println(" | DATA");
    }

    if (rpm > maxRPM) {
      maxRPM = rpm;
    }

    if (mph > maxMPH) {
      maxMPH = mph;
    }

    if (elapsed >= STARTUP_EXCLUSION) {

      if (rpm > 0) {

        rpmSum += rpm;
        rpmSamples++;
      }
    }

    if (zeroIntervals >= ZERO_INTERVAL_LIMIT) {

      Serial.println();
      Serial.println("No movement detected for 2 seconds.");

      finishRun(false);

      return;
    }

    if (elapsed >= TEST_DURATION) {

      finishRun(true);

      return;
    }
  }
}

void finishRun(bool completed) {

  runActive = false;

  digitalWrite(runningLed, LOW);
  digitalWrite(finishedLed, HIGH);

  float avgRPM = 0;

  if (rpmSamples > 0) {
    avgRPM = (float)rpmSum / rpmSamples;
  }

  float circumferenceMM =
    rollerDiameterMM * 3.14159;

  float avgMPH =
    avgRPM * circumferenceMM * 60.0 /
    1609344.0;

  Serial.println();
  Serial.println("================================");

  if (completed) {
    Serial.println("       30 SECOND RUN COMPLETE");
  } else {
    Serial.println("          INCOMPLETE RUN");
  }

  Serial.println("================================");

  Serial.print("Run Time: ");

  if (completed) {
    Serial.println("30.00 seconds");
  } else {
    unsigned long actualTime =
      millis() - runStartTime;

    Serial.print(actualTime / 1000.0, 2);
    Serial.println(" seconds");
  }

  Serial.println();

  Serial.println("--- RESULTS ---");

  Serial.print("Average RPM: ");
  Serial.println(avgRPM, 1);

  Serial.print("Average MPH: ");
  Serial.println(avgMPH, 2);

  Serial.print("Max RPM: ");
  Serial.println(maxRPM);

  Serial.print("Max MPH: ");
  Serial.println(maxMPH, 2);

  Serial.println();

  if (!completed) {
    Serial.println("Run was NOT counted as a valid");
    Serial.println("30-second test.");
  } else {
    Serial.println("Valid 30-second test.");
  }

  Serial.println();
  Serial.println("================================");
  Serial.println("Ready for next run.");
  Serial.println("================================");
  Serial.println();

  zeroIntervals = 0;
  rpmSum = 0;
  rpmSamples = 0;
  maxRPM = 0;
  maxMPH = 0;
}

void countPulse() {

  pulseCount++;
}
